## Information
- *title*: Unsupervised Representation Learning with Deep Convolutional Generative Adversarial Networks
- *author*: Radford, A., Metz, L., & Chintala, S.
- *conference*: ICLR 2016
- *task*: image generation

## Overview
### Background
At that time, prior research had failed to successfully integrate CNN architectures into GAN frameworks, as training tended to become unstable.
### Breakthrough
The authors systematically investigated and modified CNN architectures within the GAN framework, and identified several key design principles that enabled stable integration of CNNs into GANs.

### Abstract
The paper proposes a novel architecture, *Deep Convolutional Generative Adversarial Network (DCGAN)*, which is capable of learning meaningful feature representations from unlabeled data that can be transferred to downstream supervised tasks.

**Contributions**
- Proposes the DCGAN architecture.
- Demonstrates that the discriminator learns transferable features that can be used for image classification tasks.
- Provides visualizations of the features learned by GANs.
- Shows that images generated by the generator exhibit vector arithmetic properties in the latent space, e.g. `smiling man − man + woman ≈ smiling woman`.

### Pooling Layers
Replace any pooling layers with strided convolutions (discriminator) and fractional-strided convolutions (generator).

This allows the network to learn its own spatial downsampling.

### Fully Connected Layer
> [!lime]
> *global averaging layer*: increased model stability but hurt convergence speed

DCGAN avoids fully connected hidden layers inside the network. It almost uses convolutional layer.
- Generator (first layer):  
    The input noise vector $z$ is transformed via a matrix multiplication and reshaped into a four-dimensional tensor, which serves as the starting point of the convolutional stack.
- Discriminator (final layer):  
    The final convolutional feature maps are flattened and directly fed into a single sigmoid output unit.
### BatchNormalization
> [!lime]
> BatchNorm helps deal with training problems that arise due to poor initialization and helps gradient flow in deeper models.  However, directly applying batchnorm to all layers however, resulted in sample oscillation and model instability. 

Use batchnorm in both the generator and the discriminator.
To avoid instability, the paper did not apply batchnorm to the generator output layer and the discriminator input layer.

### Activation Function
> [!lime]
> observed that using a bounded activation allowed the model to learn more quickly to saturate and cover the color space of the training distribution.

- Use ReLU activation in generator for all layers except for the output, which uses Tanh.
- Use LeakyReLU activation in the discriminator for all layers.

## Experiments
### Deduplication
It is necessary to verify that DCGAN is not merely memorizing the input data. However, if the dataset itself contains many duplicate or near-duplicate images, the generator may naturally produce repeated samples.

One of the datasets used, **LSUN**, contains approximately **3 million images**, making manual inspection infeasible. Therefore, a **deduplication** procedure was applied:
1. All images were downsampled and center-cropped to $32 \times 32$ resolution.
2. A denoising, dropout-regularized ReLU autoencoder with architecture $3072 \rightarrow 128 \rightarrow 3072$ was trained.
3. The hidden layer produced semantic hash codes, which were used to measure image similarity.
4. In total, 275,000 duplicate images were removed from the dataset.

### Downstream Evaluation
To evaluate the quality of representations learned in an **unsupervised** manner, the features learned by DCGAN are extracted and used in a **supervised** classification task to measure accuracy.

*Procedure*
1. Train DCGAN on ImageNet-1k.
2. Extract convolutional features from the discriminator, applying max-pooling at each layer to obtain $4 \times 4$ spatial grids.
3. Flatten and concatenate all pooled features to form a 28,672-dimensional vector.
4. Use these vectors as training data to train an L2-regularized linear SVM.

*Baseline*: Classification using a simple K-NN classifier.

*Results*: Performance is lower than Exemplar CNN, but since DCGAN was trained on a different dataset, it demonstrates strong cross-domain generalization ability.

*Ablation*: To verify that the good performance is not solely due to the CNN architecture, a model using only the CNN features was trained. The resulting validation error was 28.7%, indicating poorer performance.

### Investigation
#### Latent Space
To examine whether the generator has learned a smooth and semantically meaningful latent space.

Interpolation is performed between latent vectors $z_1$ and $z_2$​, producing images that vary continuously.
![[截圖 2025-12-27 下午1.16.52.png]]

#### Discriminator Features
**Guided backpropagation** is used to visualize which regions of an image activate specific filters in the discriminator.

![[截圖 2025-12-27 下午1.17.09.png]]

- The left image shows randomly initialized features, which do not respond semantically to the image and appear as random noise.
- The right image shows trained features, which respond to specific semantic objects such as beds, windows, and other meaningful elements.

#### Generator Representation
Each feature map corresponds to certain semantic objects.
- Activations are extracted from the second-to-last convolutional layer of the generator.
- A logistic regression is trained to identify which feature maps contribute to generating specific objects, e.g., "windows".
- After training, masking these feature maps during generation results in the corresponding objects disappearing from the generated images.

This demonstrates that the generated images exhibit a vector-like structure in the latent space.

## Discussion
### Future Works
Even with longer training, some filters may still collapse into a single oscillatory mode (mode collapse). Further research is needed to address this issue.
